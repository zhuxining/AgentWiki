# 配置说明

AgentWiki 的全部运行参数集中在一个 JSON 文件里。配置不使用环境变量，也不支持命令行
覆盖，避免同一台机器上出现「实际生效值」和「文件里写的值」不一致。

## 配置文件位置

配置文件位置在用户配置目录下的 `~/.agentwiki/config.json`。首次运行时如果该文件不存在，
程序会写入一份默认配置，因此这个配置文件位置始终是可靠的入口。

解析顺序只有一步：读取 `~/.agentwiki/config.json`，用 Pydantic 校验，校验失败则启动报错
并指出字段名，不会静默回退到默认值。如果希望换一个配置文件位置，需要显式传入
`--config`，它只影响当前进程。

## 配置字段

### 索引路径

`index_path` 决定 SQLite 派生索引写到哪里，默认是 `~/.agentwiki/index.sqlite3`。索引路径
可以指向任意可写目录，但必须和 Wiki 根目录分开——索引是可删除派生物，和 Markdown 事实源
混在一起会让归档策略变得难以判断。

单元测试和基准测试会显式传入临时索引路径，不污染用户的正式索引。

### embedding_model

`embedding_model` 指定本地语义检索的模型标识，默认是 `BAAI/bge-small-zh-v1.5`。语义检索
依赖这个模型，把它留空则语义检索不可用，此时关键词检索仍然必须能正常工作。

换模型必须重新标定 `similarity_threshold`，因为不同模型的余弦相似度分布完全不同。曾经
出现过沿用英文模型阈值导致正确结果被全部拒绝的情况。

### similarity_threshold

`similarity_threshold` 是语义候选的相似度下限，低于该值的候选会被丢弃。它的作用是把
「没有任何文档真正相关」这种情况识别成弃答，而不是硬返回一个最近似的片段。

## 最近配置变化

最近一次配置变化把默认 embedding 模型从英文单语模型换成了多语言模型，原因是中文改写
查询在英文模型下几乎无法命中。同一次变化把相似度阈值从 0.55 调到 0.30。

更早的一次配置变化引入了 `scope` 的层级匹配，让 `guides` 这样的范围可以覆盖其子目录。
